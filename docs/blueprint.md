# **App Name**: Traffic Brain Dashboard MVP

## Core Features:

- Dashboard Layout: Responsive dashboard layout with a fixed sidebar, header, and main content area.
- KPI Cards: Display five key performance indicators (KPIs) in card format: Total Investment, Leads Generated, Estimated Revenue, Average ROAS, and Cost per Lead.
- Data Visualization: Comparative line chart displaying daily spending, conversions, and revenue trends.
- Mock Data: Implement mock data to simulate real-time data for demonstration purposes.
- Loading State: Simulate a loading state for data fetching to provide a better user experience during initial load or data updates.
- Error Handling Simulation: Simulate error states for scenarios where data retrieval fails or is incomplete.

## Style Guidelines:

- Primary color: Deep Indigo (#4C6FFF) for a tech-focused, premium feel.
- Background color: Dark navy blue (#1A202C) with 20% saturation for a minimalist tech aesthetic.
- Accent color: Teal (#00FFB3), approximately 30 degrees to the 'left' of the primary hue, creates an excellent contrast and complements the tech vibe.
- Font: 'Sora' (sans-serif) for headers, 'Inter' (sans-serif) as a fallback, for a clean, modern appearance.
- Apply a light glassmorphism effect (backdrop-blur) to the cards, set against dark backgrounds, to create depth and a premium feel.
- Ensure components are responsive across mobile (375px) and larger screen sizes using Tailwind CSS breakpoints (sm, md, lg, xl).
- Use minimalist, tech-themed icons.
